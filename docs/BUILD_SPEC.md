# Accepted Dream desktop scope

## Current desktop experience — October 7, 2026

The dashboard and Japan workspace references supplied for this revision govern the light home/AI interface. Use a centered prompt, attachment menu, suggestion chips, and real project cards. The desktop creates and names local project folders automatically; there is no login gate or account avatar.

The left AI sidebar contains Chat/Media tabs and the composer. First generation shows the actual preparation/edit activity with “Cooking up your video” and hides the timeline. A completed playable first draft persists its milestone and reveals a compact timeline. Later changes animate only committed items and dim only the preview UI. Pauses, file approvals and failures stop working animations. Reduced motion is supported.

Manual mode uses a charcoal/teal asset-player-inspector layout over a full-width timeline. Functional categories include media, audio, text, elements, effects, transitions, captions and adjustment. The magnetic main track and freely positioned attached tracks retain existing model semantics. Aspect ratios and visual styling are shared with export.

Computer access is requested from the attachment menu or Settings. File browsing is paginated and cancellable. The user approves exact existing-file edits, moves, renames and Trash operations, with text before/after views where applicable. New requested files and copies may complete within the granted scope. OS-level protected-folder restrictions remain authoritative.

Implement an installable Windows 11 x64 and macOS 14+ Apple Silicon editor. The interface is packaged locally and follows `reference/editor.png`: approximately 73% light preview/timeline workspace and 27% full-height dark language-editing sidebar.

Local responsibilities include project folders, SQLite history, linked/copied originals, proxies, offline analysis, local playback, deterministic generated media and MP4 export. Accounts, invitations, authenticated model inference, explicit finished-export sharing and updates use cloud services. There is no project cloud synchronization or billing in the invite-only beta.

The complete journey is invitation/setup, local project creation, native import, editable outline approval, real committed timeline updates, iterative editing, reversible versions and branches, original procedural media, local export and optional revocable viewing link. Existing local work remains available offline after setup.

Canonical tracks are Video, B-roll, Overlays, Captions, Music and SFX; hide empty tracks. Manual controls include selection/ranges, playback/scrubbing, zoom, delete and undo/redo. Default format is 1920×1080 at 30 fps, with 16:9, 9:16 and 1:1 at 720p or 1080p.

Required analysis includes Whisper transcription, word alignment, speakers, scene detection, sampled frames, loudness/silence/beats/events, face tracking, semantic shot logs and local embeddings. Models and native runtimes must ship or install through verified managed downloads. Users do not install development tools.

AI runs a local orchestrator through authenticated inference. First builds require outline approval. Operation batches are atomic, version-checked and idempotent; cancellation preserves committed edits. Structural edits receive actual rendered review packets. Resuming an interrupted turn must not repeat completed mutations.

Creation includes 50 curated instrumental score presets, 40 SFX presets, editable deterministic arrangements/stems and reusable graphics. Generated visual code must execute only in a separate sandbox without editor IPC, credentials, Node or external network. Preview and export consume immutable captured assets and shared timing.

Acceptance requires packaged offline import/export on both targets, persistence/collection/relink recovery, real long-source analysis and AI editing, complete invited-user journeys, signed installers/updates and measured performance. Sources up to two hours and projects up to four hours must be supported. The broader-launch quality target is at least 60% project-weighted preference over the nonprofessional baseline in 20 projects with at least five ratings per pair, including category results and uncertainty.

The implementation is not complete until these behaviors and delivery artifacts are verified. `ARCHITECTURE.md` maps the source; `CODE-ENGINE.md` describes Roux, the agent.
